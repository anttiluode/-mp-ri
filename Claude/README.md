# Claude branch

This directory preserves a separate experiment line written by Claude. It is not imported by the core `mpri` package.

The point of keeping it separate is provenance: the core repo began with explicit vortex objects as persistent weights, while Claude independently attacked two simpler questions on a different 2-D incompressible vorticity solver.

## Files

- `ns_core.py` — 64×64 periodic pseudo-spectral 2-D Navier–Stokes/vorticity solver with ETD-RK2 time stepping.
- `setup_geom.py` — fixed background geometry: two counter-rotating vortices create a shear channel, with two input sites and one downstream probe.
- `run_additivity.py` — runs `base`, `A`, `B`, and `AB` cases while sweeping input separation; compares `dAB` with `dA + dB` using raw downstream patch vectors.
- `Run_xor.py` — generates 88 jittered trials (22 per bit pair), injects the two bits as signed vortex packets, evolves the fluid, and stores a 13×13 downstream patch as the feature vector.
- `eval_xor.py` — trains a linear logistic-regression readout on raw bits, the full flow patch, and a two-feature summary.
- `xor_data.npz` — stored dataset generated by `Run_xor.py`.

## Recorded XOR run

```text
=== Baseline: linear readout on the RAW BITS themselves ===
XOR: 0.408 +/- 0.035
OR:  1.000 +/- 0.000
AND: 1.000 +/- 0.000

=== Linear readout on the FLOW's downstream patch ===
XOR: 1.000 +/- 0.000
OR:  1.000 +/- 0.000
AND: 1.000 +/- 0.000

=== Only mean vorticity and mean |vorticity| ===
XOR: 0.707 +/- 0.077
OR:  1.000 +/- 0.000
AND: 0.966 +/- 0.045
```

Interpretation: a linear classifier cannot solve XOR from the raw two-bit representation, but XOR becomes linearly readable after the nonlinear fluid evolution. This is evidence that the medium is doing genuine nonlinear feature construction.

It is **not a novelty claim**. Fluid/wave reservoir computing has long used exactly this kind of benchmark. In this repository the XOR result is a substrate sanity check before the harder question: can the computation rewrite persistent routing structures in the same medium?

## Running it

From this directory:

```bash
python Run_xor.py
python eval_xor.py
```

`eval_xor.py` needs `scikit-learn` in addition to NumPy.

The stored `xor_data.npz` means the evaluator can also be run without regenerating the simulations:

```bash
python eval_xor.py
```

The additivity sweep is separate:

```bash
python run_additivity.py
```

That experiment is especially relevant to the CausalHorizon/Kompressori line because it measures the failure of superposition on raw downstream field vectors instead of manufacturing a cross-term in a nonlinear detector.
